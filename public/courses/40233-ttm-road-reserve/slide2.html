Welcome

~3 min read

Welcome to Module 1 of the TTM Fundamentals learning pack. This module plays immediately after the course introduction video, so it doesn't start from zero — the video has already covered why TTM safety matters and previewed all four skills this course builds: spotting hazards and checking risks, TMP alignment and safe operations, clear communication and active control, and protecting vulnerable road users. Module 1 is where the first of those starts: spotting hazards, and understanding how they actually cause harm.

This module is built against Skill Standard 40233 Assist with temporary traffic management within the road reserve (NZQA, Level 3, 5 credits). Standard 40233 sits within a small family of road-reserve skill standards — 40232 (mobile operations) and 40517 (supervising a mobile operation) cover related ground — and its first indicative content point is exactly what this module teaches: common onsite hazards in the TTM industry and how they cause harm.

By the end of this module you will be able to define the road reserve and the TTM zone using the standard's own definitions, describe how each common onsite hazard actually causes harm — not just name it — and know where to go for further WorkSafe good-practice guidance.

By the end of this section you can:

  • State the purpose of Module 1 and how it maps to Standard 40233
  • Explain why “how a hazard causes harm” matters as much as naming the hazard itself
NOTE

Platform sequencing: this module is designed to play directly after the course introduction video (Skill_Standard_40233_Introduction.mp4, ~80 seconds). Because the video already frames the whole course — its four skill areas and the online-then-practical structure — this Welcome section deliberately does not repeat that framing. If Module 1 is ever used without the intro video ahead of it (e.g. as a stand-alone refresher), restore a fuller course overview here.

NOTE

This module is a knowledge foundation, not a competency assessment. Standard 40233's own assessment specifications require achievement to be assessed where the PCBU has provision for a level of supervision appropriate to the learner's role — this e-learning module builds the shared understanding a learner brings to that supervised, on-the-job assessment.

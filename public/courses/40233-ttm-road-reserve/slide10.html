Welcome

~3 min read

Welcome to Module 2 of the TTM Fundamentals learning pack — Risk Assessments and TMP Alignment. Module 1 covered the road reserve, the TTM zone, and the six common onsite hazards, and how each one causes harm. This module builds directly on that: it's where you learn to check whether the risk assessment you're working to still matches what's actually happening onsite.

This module targets Learning Outcome 1a of Skill Standard 40233: risk assessment is checked to include any new risks and alignment with the TMP. That single sentence covers two related skills — recognising when a site has changed enough to introduce a new risk, and knowing how to check that the Traffic Management Plan (TMP) you're working to still fits reality.

By the end of this module you'll be able to explain what a risk assessment and a TMP actually are, apply the hierarchy of controls to a site-specific risk, use the same onsite checks a TTM reviewer uses to confirm a risk assessment still reflects reality, and know what your organisation's policies, procedures, and practice notes require of you.

By the end of this section you can:

  • State the purpose of Module 2 and how it maps to Learning Outcome 1a
  • Explain the relationship between a risk assessment, a TMP, and organisational requirements
NOTE

This module assumes you've completed Module 1. If a hazard type mentioned here (an environmental hazard, a vulnerable road user issue) isn't familiar, revisit Module 1's Hazard Spotting activity before continuing.

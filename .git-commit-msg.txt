Admin: show where each learner is up to in every course

The Learners panel could only show quiz attempts and completions, so a
learner looked "Not started" until they reached a quiz -- and ASHTAS-01
(Operative) never recorded anything at all. Slide progress only lived in
the learner's own browser.

- New public/js/progress-sync.js: reads each course engine's existing
  saved progress (never changes it) and copies a summary to
  course_progress/{uid}__{courseId}: screens done/total, %, current
  slide/step, quizzes passed, content complete, started/updated.
  Writes only when something changes; done/% only ever go up so a
  second device can't wipe real progress. Handles all five engines
  (Course decks, CourseProgress/PTS-01, ASHTAS CourseNav, NZGTTM/Roles
  screens, Engineering Essentials slides).
- home-button.js (on every course page) loads it -- no course pages edited.
- firestore.rules: course_progress -- learner writes own doc only,
  admins read all.
- admin-learners.js / admin.html: new "Currently working on" column,
  and per-course progress bar + position in the learner profile
  ("In progress" / "Content complete"). Course matching now also falls
  back to the page's course folder, so PTS-01 records (courseId
  "pts-01") match the catalog entry.

Deploy needs rules as well as hosting:
  firebase deploy --only firestore:rules,hosting
